## 📌 使用说明（重要）

- **`notes/week01/` 里的 md 是空白引导模板**：只给了"要学什么 + 引导问题"，内容全部由你自己写——写笔记的过程就是学习本身。
- **`_reference/week01/` 是参考答案**（已加入 `.gitignore`，**不会推送**，仅本机对照用）：每篇学完、自己写完后再打开对照，查漏补缺。**不要先看答案再抄。**
- 每天结束：`git add . && git commit -m "docs(notes): dayNN 主题" && git push`
