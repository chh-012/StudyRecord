## 二、项目 3 轻量版定义（先看清楚做什么）

**一句话**：一个**能吃你自己的文档、回答问题、带来源引用**的 Agent 问答应用（Gradio/Streamlit 界面，可当场演示）。

**技术栈**（全部是你已学过的）：
```
界面：Gradio 或 Streamlit（选一个，最省事）
后端：Python + LangChain
检索：Milvus Lite（或 Chroma，Week8 都试过）
模型：DeepSeek（chat）+ BGE（embedding）
评测：Week8 写的测试集 + 评测脚本
```

**本周不做**（留给完整版 11/5-11/22）：
- ❌ FastAPI 后端分层、Vue3 前端
- ❌ Function Calling / 多工具
- ❌ Rerank 精排、混合检索（有余力再说）
- ❌ 部署到服务器

**验收标准（本周结束时能演示给别人看）**：
1. 打开界面 → 上传/选择文档 → 提问 → 得到带来源的回答
2. 问文档里没有的 → 明确说"资料中未提到"
3. 有一个 Demo 视频（1-2 分钟）
4. 有 README（怎么跑起来）

**⏰ 上午 1.5h + 下午 2h ｜ 写 `rag_chain.py`**
```python
# 目标结构
retriever = ...                       # Milvus 检索器
prompt = ChatPromptTemplate(...)      # system 约束 + context + question
chain = {"context": retriever | format_docs, "question": RunnablePassthrough()} | prompt | llm | StrOutputParser()
def ask(q): return chain.invoke(q)    # 或 stream
```
