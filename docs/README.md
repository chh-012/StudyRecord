## 📌 使用说明（重要）

- **`_reference/weekNN/` 是每周知识点详细总结**（AI 编写，已加入 `.gitignore`，**不推送**，仅本机使用）：学完对应知识点直接阅读，作为学习材料。
- **`notes/weekNN/` 存放你的练习代码**（如 `py笔记/day1.py`）：练习产出可自行提交，笔记本身不再手写。
- 每天结束：`git add . && git commit -m "docs(notes): dayNN 主题" && git push`
