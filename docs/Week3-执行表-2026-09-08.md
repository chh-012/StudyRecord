## 三、Java 深度定位（A 方案对照表，本周 Java 课照此执行）

| 知识点 | 目标深度 | 学什么 | 明确不学什么 |
|------|:---:|------|------|
| Java 语法 | L2 | 集合/Stream/泛型/异常，能写 CRUD | 不追并发/反射深挖 |
