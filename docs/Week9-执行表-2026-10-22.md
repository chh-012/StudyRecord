### Day 1 ｜ 10/22 周四 ｜ 🔧 Function Calling 深化（L2→L3）

> **今日目标**：掌握多工具路由 + 参数校验 + 工具报错恢复
> **完成标准**：定义 4 个工具，模型能正确选择；工具报错时 Agent 能优雅处理而非崩溃

**⏰ 上午 1h ｜ 学概念**
- 回顾 → `_reference\week05\week05-agent7-function-calling.md` **§1、§4**（基础机制 + 面试问答）
- 新读 → hello-agents **第 4 章 / 第 6 章**（工具调用部分）；B站搜「Function Calling 多工具」「Agent 工具调用 最佳实践」
- 重点搞懂：
  1. 工具描述（description）如何影响模型选择
  2. **参数 schema 校验**（required / enum / 类型）
  3. 工具执行失败时，如何把错误**回传给模型**让它自我修正
  4. 并行工具调用是什么场景
- ✅ 自检：能说出"模型选错工具"的 3 个原因

**⏰ 上午 1h ｜ 动手（照抄档）**
- 在 `notes\agent-tools` 目录（沿用 Week7 的 venv）
- 定义 4 个工具：`search_notes`（查笔记）、`calculator`（计算）、`get_time`（当前时间）、`query_news`（模拟查资料，返回固定数据）
- **预期看到**：`verbose` 打印出模型选了正确的工具
- 卡住 → 检查工具 `description` 是否写清"什么场景用"

**⏰ 下午 3h ｜ 练习**
1. **半开卷**：自己写 4 个工具的 schema（不看代码）
2. **路由测试**：设计 8 个问题，覆盖 4 个工具 + 1 个"不需要工具"，统计选择正确率
3. **错误恢复**：让 `calculator` 对非法输入返回错误信息，观察模型是否**换个参数重试**
4. **并行调用**：问一个需要同时查两件事的问题（如"现在几点 + Redis 是什么"），看模型是否并行调两个工具
5. **闭卷**：默写"工具定义三要素 + 调用循环三步"

**⏰ 晚上 0.5h ｜ 默写 + 卡点**
- 记录：路由正确率 / 错误处理表现

### Day 3 ｜ 10/24 周六 ｜ 🔌 MCP 协议（上）：概念 + 手写 Server

> **今日目标**：搞懂 MCP 是什么，并写出一个能被调用的 MCP Server
> **完成标准**：`python server.py` 能启动，且有 1-2 个工具被客户端识别

**⏰ 上午 1h ｜ 学概念**
- 读 → hello-agents **第 10 章**（智能体通信协议：MCP/A2A/ANP）
- 读 → MCP 官方中文文档 `https://modelcontextprotocol.io`（或搜「MCP 协议 中文 入门」）
- 重点搞懂：
  1. **MCP 三要素**：Tools（可调用的函数）/ Resources（可读的数据）/ Prompts（可复用的提示模板）
  2. **Client-Server 架构**：谁提供能力（Server）、谁消费（Client，如 Claude Desktop）
  3. **MCP 与 Function Calling 的区别**（FC 是模型 API 层；MCP 是标准协议，工具可复用给任何客户端）
- ✅ 自检：能说清"为什么 MCP 比每个应用自己写工具更有价值"

**⏰ 上午 1h ｜ 动手（照抄档）**
- 装 SDK：`python -m pip install mcp`
- 写一个最小 MCP Server（暴露 1-2 个工具，如"查笔记""算数"）
- **预期看到**：`python server.py` 启动无报错（stdio 传输模式下会等待客户端连接）
- 卡住 → 查官方 quickstart；确认 Python 版本（3.11）

**⏰ 下午 3h ｜ 练习**
1. **半开卷**：只留 `@server.tool()` 装饰器，自己补工具实现
2. **加 Resources**：除了工具，再暴露一个"可读资源"（如某个笔记文件）
3. **测工具描述**：改工具 description，观察（后续接入时）客户端如何呈现
4. **闭卷**：默写"MCP 三要素 + Server 最小结构"

**⏰ 晚上 0.5h ｜ 默写 + 卡点**

> **📚 资源**：B站搜「MCP 协议 入门」「MCP Server 开发」 ｜ MCP 官方文档 `https://modelcontextprotocol.io` ｜ hello-agents 第 10 章
